# 紫微斗数排盘程序

这是一个基于Python的紫微斗数排盘程序，可以根据出生年月日时计算紫微斗数命盘。

## 文件说明

1. **ziwei_app.py** - 完整的紫微斗数排盘程序
   - 包含十二宫排列
   - 十四主星安星
   - 四化星计算
   - 交互式输入界面
   - 结果保存功能

2. **test_ziwei.py** - 测试脚本
   - 测试基本计算功能
   - 测试完整命盘计算
   - 测试多个案例

3. **simple_test.py** - 简单测试脚本
   - 不依赖外部库
   - 直接运行测试

4. **run_test.bat** - Windows批处理文件
   - 自动检测Python环境
   - 运行测试脚本

## 使用方法

### 方法1：直接运行主程序
```bash
python ziwei_app.py
```

### 方法2：运行测试
```bash
python test_ziwei.py
```

### 方法3：运行简单测试
```bash
python simple_test.py
```

### 方法4：使用批处理文件（Windows）
双击 `run_test.bat` 文件

## 程序功能

### 1. 输入出生信息
- 出生年份（如：1990）
- 出生月份（1-12）
- 出生日期（1-31）
- 出生时辰（0-23）
- 出生分钟（0-59）
- 性别（男/女）

### 2. 计算内容
- 命宫位置
- 身宫位置
- 紫微星位置
- 十二宫排列
- 星曜分布
- 四化星计算

### 3. 输出结果
- 命盘摘要
- 十二宫星曜分布
- 四化星信息
- 可保存为JSON文件

## 算法说明

### 简化算法
由于完整的紫微斗数算法非常复杂，本程序使用了一些简化算法：

1. **命宫计算**：`(月份 + 时辰) % 12`
2. **身宫计算**：`(月份 + 时辰 + 6) % 12`
3. **紫微星计算**：`(日期 + 5) % 12`
4. **四化星计算**：基于年份个位数的简化对应表

### 注意事项
1. 实际紫微斗数需要农历日期，本程序暂用公历简化
2. 实际安星算法更复杂，本程序使用简化版本
3. 四化星的实际计算基于天干地支，本程序使用简化对应
