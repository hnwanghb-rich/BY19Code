# 紫微斗数排盘系统

一个完整的紫微斗数排盘工具，包含农历公历转换、命盘计算、运势分析和报告生成功能。

## 快速开始

### Windows 用户
1. 双击运行 `run_ziwei_complete.bat`
2. 程序会自动安装依赖并启动

### 其他系统
```bash
# 安装依赖
pip install zhdate markdown pypinyin jinja2

# 运行程序
python ziwei_gui_complete.py
```

## 主要功能

### 🌙 农历公历转换
- 公历 ↔ 农历双向转换
- 显示生肖和闰月信息

### 📊 紫微斗数排盘
- 命宫、身宫计算
- 十二宫星曜分布
- 四化星（禄、权、科、忌）
- 五行局确定

### 🔮 运势分析
- 未来五年运势预测
- 健康、事业、财运、感情分析
- 吉利方位和颜色建议

### 📄 报告生成
- **MD报告**：Markdown格式，兼容性好
- **JSON数据**：结构化数据，适合程序处理
- **HTML报告**：美观网页，支持打印

## 文件说明

| 文件 | 说明 |

| `ziwei_gui_complete.py` | 完整GUI应用程序 |
| `run_ziwei_complete.bat` | Windows启动脚本 |

| `test_complete_system.py` | 功能测试脚本 |
| `紫微斗数系统使用说明.md` | 详细使用文档 |

## 使用步骤

1. **输入信息**：填写姓名、性别、出生日期和时间
2. **日期转换**（可选）：验证农历公历转换
3. **排盘分析**：点击按钮开始计算
4. **查看结果**：在选项卡中查看命盘和运势
5. **导出报告**：生成MD/JSON/HTML格式报告
